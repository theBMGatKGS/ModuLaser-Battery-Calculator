  3. Display rows are collapsed to a single current value each, per the calculator's own model (which does not distinguish TFT or LEDS state) — the TFT-On/LEDS-On (highest-draw) state was used to select the corresponding 18V figure.
  4. ¹ Minimum Display: the manufacturer worksheet publishes only the LEDS-Off state for this display (no TFT) at 18V — no LEDS-On figure is available in the source data, so 242 mA is the highest published value rather than a true TFT-On/LEDS-On worst case.
  5. ² Command Display: no separate current-draw entry exists for this display in the source manufacturer table. This reuses the Standard Display figure, consistent with the calculator's own treatment of both display types as electrically identical (FHSD8310-ULF and FHSD8320-ULF share the same 232 mA rating in the calculator).
